Calculadora em Python

Projeto pessoal desenvolvido durante meus estudos de Engenharia de Software para praticar lógica de programação e os fundamentos de Python.

Funcionalidades:

Soma, subtração, multiplicação e divisão.
Tratamento de divisão por zero.
Validação de operações inválidas.
Tratamento de entradas numéricas inválidas.
Repetição de operações sem precisar reiniciar o programa.

Tecnologias:

Python 3
Visual Studio Code

Como executar:

Instale o Python 3.
Baixe este repositório.
Abra um terminal na pasta do projeto.

Execute:

python calculadora.py
No Windows, também é possível executar com py calculadora.py.

Objetivo:

Praticar estruturas condicionais, loops, conversão de tipos e tratamento de erros em Python.
